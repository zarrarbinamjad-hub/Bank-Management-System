# 🏦 Bank Management System

A simple **Bank Management System** console application developed using **C#**.

## 📌 Project Overview

This project is a console-based Bank Management System created to practice **C# Object-Oriented Programming (OOP)** and programming logic.

The system manages multiple customers and provides basic banking operations such as opening accounts, depositing money, withdrawing money, searching customers, and removing accounts.

## 🚀 Features

- Open a customer account
- Store multiple customers using `List<Customer>`
- Display customer information
- Show all customers
- Search customer by account number
- Deposit money
- Withdraw money
- Show customer balance
- Remove customer account
- Calculate total money in the bank
- Find the customer with the lowest balance
